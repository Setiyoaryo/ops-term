# OpsTerm v0.1.5

This release focuses on terminal compatibility: keyboard input, application
cursor modes, mouse reporting, and truecolor/theme detection for TUIs such as
ncdu, htop, Codex, and opencode.

## Terminal input

- Arrow, Home, End, Insert, Delete, PageUp/PageDown and F1–F12 now follow
  DECCKM application-cursor mode (`?1h`) instead of always sending CSI
  sequences. ncdu, htop, `less`, vim and other ncurses programs receive the
  expected SS3/CSI forms.
- Ctrl/Alt/Shift-modified cursor and editing keys now use standard xterm
  sequences (`CSI 1;m` and `CSI n;m~`).
- Alt+Left/Right keep the Ctrl+Arrow word-jump sequences used by Linux shells.
- Ctrl+A, Ctrl+V and Ctrl+X are delivered to the running application
  (`0x01`, `0x16`, `0x18`). Select-all, paste and copy use Ctrl+Shift+A,
  Ctrl+Shift+V/Shift+Insert, and Ctrl+Shift+C/Ctrl+Insert.
- Bracketed paste, IME commit text, focus reporting, and function keys are
  supported.

## Mouse and full-screen applications

- xterm mouse reporting is implemented for click, drag, motion and wheel, with
  SGR (`?1006`) and legacy X10 encoding.
- Wheel events reach applications that enable mouse tracking, including the
  opencode/opentui chat view. Shift+wheel retains local selection/scroll.
- Full-screen apps without mouse reporting receive wheel as arrow keys
  (alternate scroll), matching xterm/Tabby.

## Colors, themes, and terminal replies

- Local shells now advertise `COLORTERM=truecolor`, `TERM_PROGRAM=OpsTerm`, and
  `COLORFGBG=15;0`. Codex/opencode no longer downgrade their own theme to the
  terminal's 256-color palette.
- Terminal replies for DA1/DA2, DSR, OSC 4/10/11 and text-area size are routed
  back to the PTY. OSC 52 clipboard-store is supported.
- Reverse video (SGR 7) and underline are rendered. ncdu/htop/mc selection bars
  are visible and move with the keyboard.

- Clippy passes with `-D warnings`; formatting is clean.
