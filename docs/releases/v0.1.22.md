# OpsTerm v0.1.22

Command library and a cleaner command bar, faster terminal navigation, and
serial quick connect.

- **Tools → Command library** adds, edits, deletes, searches, and sends saved
  commands, including vendor profile and tags. The command bar above the
  composer now has a filter, compact scrolling chips, and a **Manage…** shortcut.
- `Ctrl+F` toggles the terminal find bar, focuses its search field, and `Esc`
  closes it.
- `Ctrl+T` now opens the connect palette even on platforms that report the
  primary modifier as Control only.
- Serial quick connect: type `/dev/ttyUSB0 115200` or
  `serial /dev/ttyUSB0 115200` in the connect palette. A bare device path uses
  9600 8N1, and unsupported baud rates are rejected. Serial remains Unix-only.
- Highlight rules and the keyword-highlight toggle now persist in the egui
  settings, so updates and restarts no longer reset them.

Verification: 180 egui tests and 74 core tests pass, along with Linux clippy
(`-D warnings`) and `cargo check` for the `x86_64-pc-windows-gnu` target.
