# OpsTerm v0.1.4

GNS3 can launch OpsTerm directly into a node's Telnet console, with the node name as the tab and window title.

In **GNS3 → Edit → Preferences → General → Console applications**, edit **Console application command for Telnet**:

```text
/home/portego/.local/bin/opsterm-egui --telnet "{host}" --port {port} --title "{name}"
```

Use your own installation path. Each launch creates one separate OpsTerm window containing the requested Telnet tab. Existing windows are not reused; no extra local shell or saved-device entry is created. No external `telnet` program is needed. VNC console configuration stays separate.

The normal egui interface, appearance preferences, clipboard behavior and close confirmation are retained. Launches without arguments still start Local Shell. Console arguments are validated before opening the database or GUI; `--help` and `--version` are available without a display. An external Telnet console does not need the inventory vault to be unlocked; protected inventory actions continue to require it.
