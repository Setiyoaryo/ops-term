# OpsTerm v0.1.3

Clipboard image paste for terminal CLI agents and confirmation before closing terminal tabs.

- Image-only clipboard paste now forwards Ctrl+V to the focused CLI agent; native text paste stays unchanged. Verified with a real PNG clipboard and Codex CLI 0.164.0, where the composer displayed `[Image #1]`.
- Tab X and Ctrl+Shift+W ask before closing, including disconnected tabs that retain output.
- Window X and update restart ask before closing open tabs. Cancel receives initial focus; Escape cancels; Ctrl+Enter explicitly confirms after the prompt is visible.
- Closing uses stable session IDs, and cancelling restores the previously focused editor or terminal.
- Keyboard input stays inside the close dialog so Enter cannot run the composer, Quick Connect or other background forms.
- Existing egui styling, fonts, scrolling and device inventory are preserved.

## Update

Use **Help → Check for updates → Install update**, then restart when your sessions can be closed. The update uses the existing Ed25519 trust key and SHA-256 verification.

Paste images while the CLI agent's composer is active. The agent must support clipboard image input and have access to that clipboard; this feature does not upload a local image to a remote SSH machine. If clipboard data offers both text and an image, native text paste keeps priority.

Linux x86_64 build baseline: Ubuntu 24.04. Total RAM remains dependent on the graphics driver, window size and sessions.
