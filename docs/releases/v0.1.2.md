# OpsTerm v0.1.2

Improves responsiveness when connections stop accepting input, while keeping the existing egui workspace.

- Move transport writes, resize operations and lifecycle polling off the UI thread.
- Bound pending input to 1 MiB and 64 operations; rejected input reports an error instead of waiting or silently growing memory.
- Close sessions without waiting behind a stalled write; Telnet shutdown now bypasses the blocked writer lock.
- Retry terminal resizes rejected during backpressure.
- Preserve Ctrl+C shortcut modifiers when a quick press/release is delivered in one native input frame. Ctrl+Shift+C remains copy-only.
- Remove the legacy third-party session importer and product references. CSV/TSV import/export and existing saved devices remain available.

## Install or update

Use **Help → Check for updates → Install update**, then restart when your sessions can be closed.

For manual installation, download the Linux x86_64 binary and its `.sha256` asset, verify the checksum, then install it in `~/.local/bin/opsterm-egui`.

Built on Ubuntu 24.04. Signed update metadata uses the existing Ed25519 trust key. This release fixes reproduced blocking-I/O paths; other intermittent stalls need their own reproduction. Total memory still depends on the graphics driver, terminal size and sessions.
