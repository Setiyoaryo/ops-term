# OpsTerm v0.1.20

Search-first connections, faster device search, and folders that appear right
away.

## Connect palette

- `Ctrl+T` (`Cmd+T` on macOS) opens a search-first connect dialog. The sidebar
  **T** button and **Session → Connect…** open the same palette.
- Type part of a device name, host, username, or tag; matching saved devices
  are listed first. Type `user@host` (or `user@host:port`) to connect without
  saving a device.
- `Up`/`Down` selects, `Enter` connects, `Esc` closes. While the palette is
  open, terminal input is paused.
- Search ignores spaces and punctuation, so `pe ktt`, `pe-ktt`, `PE KTT`, and
  `pektt` all match `PE-KTT-01`. Name matches are ranked above host/tag matches.
- `Ctrl+Shift+T` still opens a local shell immediately.

## Sidebar

- **Add folder** now shows the new folder immediately, even when the device
  library is empty.
- The sidebar **T** button is now a connect-palette action instead of creating a
  local shell directly.

Verification: 174 egui tests and 74 core tests pass, along with Linux clippy
(`-D warnings`) and `cargo check` for the `x86_64-pc-windows-gnu` target. The
shortcut and search behavior are covered by regression tests.
