# OpsTerm v0.1.17

Polish the restored-sidebar control and make runbooks run with clear feedback.

## Sidebar

- The `»` restore control is now a quiet, borderless chevron on a slim rail. It
  highlights only on hover instead of drawing a large rounded button.
- The rail keeps the same panel color and a single subtle divider.

## Runbooks

- The Runbooks window now shows the active target and a running indicator.
- **Run** reports why it cannot start: no active session, an empty script, an
  invalid regex, or a script already running on the session.
- **Stop** cancels the script running on the active session.
- Save validates the name in the window, and save/delete/run results are shown
  in the dialog instead of only in a background status message.
- The Run button uses the accent style and remains next to Save, Stop and
  Delete.

Verification: 170 egui tests pass, including runbook run/stop coverage and the
360 px responsive render test.
