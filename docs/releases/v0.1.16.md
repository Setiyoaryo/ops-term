# OpsTerm v0.1.16

Make the hidden devices sidebar discoverable again and keep the window usable
when it is narrow.

## Devices sidebar

- When the sidebar is hidden, a slim left rail now shows a `»` button that
  restores it. The View menu and Ctrl+Shift+B (Cmd+Shift+B on macOS) still work.
- The sidebar header switches to compact `+`, `⊞` and `«` buttons on narrow
  panels so the controls no longer overlap.
- The sidebar width limits now follow the window size instead of always
  reserving 190 px.

## Responsive layout

- The menu bar hides the brand and quick-connect field when space is limited;
  the remaining menus stay aligned instead of overlapping.
- The tab bar reserves space for a compact `+` button and shrinks tab minimum
  widths, keeping the tab strip clipped and scrollable rather than overlapping.
- The status bar keeps the connection state, truncated session title and
  terminal size visible, and drops the timer, memory, tab count and Reconnect
  button progressively as the window narrows.

Verification: 167 egui tests pass, including a render test at 360 px wide with
the sidebar both visible and hidden.
