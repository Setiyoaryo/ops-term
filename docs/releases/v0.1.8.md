# OpsTerm v0.1.8

Fix drag selection into terminal history and add automatic diagnostics for intermittent missing UI progress. The existing egui appearance, signed native/AppImage updater and Linux package baseline remain unchanged.

- Dragging above the terminal viewport now moves toward older history; dragging below moves back toward live output. Holding the pointer beyond an edge keeps scrolling and preserves the selection anchor.
- Native Xvfb regression verifies copied text includes rows outside the original viewport, rather than only checking screenshots.
- A separate watchdog records prolonged missing UI progress without waiting on UI locks. Reports contain only version, PID, time, last UI phase, kernel wait symbol and syscall number. They do not contain terminal text, commands, clipboard data, session names, hosts or credentials.
- Reports are created only when needed under the app data directory's diagnostics folder, with exclusive creation and private permissions. Each file is limited to 64 KiB; eight finished-process reports are retained alongside live-process reports.

The randomly reported “not responding” incident has not yet been reproduced or assigned a proven cause. Diagnostics are investigation support, not a claim that all freezes are fixed. Occlusion, suspension and native dialogs can also cause missing-frame observations. Existing sessions are never killed by the watchdog.
