# OpsTerm v0.1.23

Device passwords directly in the device form, plus tab reordering and renaming.

- **Add/Edit Device** now has a **Password** field in the egui client, the Tauri
  web UI and the GTK client. Saving stores the secret in the credential vault
  (or OS keyring when no vault exists) and links it to the device, so you no
  longer need to open **Tools → Credentials** first. Reconnects after an app or
  laptop restart reuse the saved password instead of prompting again.
- The password field stays blank when editing an existing device: leave it blank
  to keep the current secret, or type a new one to replace it.
- Tabs can be dragged to reorder with an animated slide. Double-click a tab, or
  right-click and choose **Rename tab…**, to give a session a custom title.
- The README documents tab reordering and renaming.

Verification: CI runs Rust format and Clippy, the core and egui test suites,
frontend unit tests and E2E, the packaging/publisher tests, signed release
assembly, and native X11/Wayland smoke checks before publishing.
