# OpsTerm v0.1.15

Keyboard compatibility for terminal editors and macOS, plus a collapsible
devices sidebar.

## Terminal keyboard

- Editor shortcuts such as nano's Ctrl+O/W/K/U/G and Ctrl+/ now send their
  expected control bytes. Ctrl+@, Ctrl+^ and Ctrl+_ are covered as well.
- A fast Ctrl+V press/release no longer pastes the clipboard by accident; the
  terminal receives `0x16` (page down in nano, quoted-insert in readline).
- Ctrl+X and Ctrl+C keep their terminal meanings and are not treated as
  application clipboard commands on Linux.

## macOS

- Command is reserved for application shortcuts and Ctrl remains the terminal
  control modifier. Menu labels and the keyboard-shortcut window show Cmd on
  macOS.
- Cmd+C/X/V/A work as native copy/cut/paste/select-all.
- Cmd+Backspace deletes to the start of the line and Cmd+Left/Right move to the
  start/end of the line, matching common macOS terminal behavior.
- Option acts as Meta (ESC prefix) instead of sending the composed character
  produced by the keyboard layout.

## Devices sidebar

- The devices sidebar can be hidden from its header button, from
  **View → Devices sidebar**, with Ctrl+Shift+B (Cmd+Shift+B on macOS), or by
  dragging its resize edge past the minimum width.
- The hidden/visible state is remembered across restarts.

## Fonts

- Custom UI fonts now keep egui's default fallback fonts, so glyphs that the
  selected font lacks (for example `▶`) render instead of appearing as `?`.

Verification: 166 egui tests pass, including new coverage for nano control
keys, fast Ctrl+V delivery, macOS Command handling and Option-as-Meta.
