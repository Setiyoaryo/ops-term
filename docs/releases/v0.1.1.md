# OpsTerm v0.1.1

First public Linux x86_64 egui release.

- Native egui workspace with local shell, SSH, Telnet and serial sessions.
- Visible hover feedback for dialog close buttons.
- Faster mouse-wheel scrolling with fractional-pixel terminal movement.
- Selectable terminal fonts, Original/Soft/Warm/Cool text palettes, brightness and live preview.
- Signed automatic updates hosted on GitHub Releases, with SHA-256 verification and a rollback copy.

## Install

Download `opsterm-egui-0.1.1-linux-x86_64` and its `.sha256` asset from this release.
In the download directory:

```bash
sha256sum -c opsterm-egui-0.1.1-linux-x86_64.sha256
install -Dm755 opsterm-egui-0.1.1-linux-x86_64 "$HOME/.local/bin/opsterm-egui"
"$HOME/.local/bin/opsterm-egui"
```

Built on Ubuntu 24.04 (glibc 2.39), for Linux x86_64 with an OpenGL-capable desktop.
Runtime libraries include D-Bus and XKB; `curl` and CA certificates are required
for HTTPS updates. Install OpenSSH for SSH/SFTP features. Other Linux versions
and alternate clients are not included in this binary release.

The app checks for signed releases automatically. Use **Help → Check for updates**
to check manually; installing an update leaves active sessions running until you
choose to restart. Settings → Appearance contains the font and palette controls.

Memory varies by driver and window size. The earlier optimization did not reach
15–30 MiB total RSS; this release makes no such memory guarantee.
