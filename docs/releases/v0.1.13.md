# OpsTerm v0.1.13

Fix a silent SSH hang when a saved OpenSSH session targets a host that is not
yet present in `known_hosts`.

- The askpass helper now answers password prompts only. Host-key confirmation
  prompts fail immediately, so OpenSSH reports `Host key verification failed.`
  on the terminal instead of waiting forever with a blank session.
- The same helper is used by the auxiliary `ssh`/`sftp`/`scp` paths, so they
  now also fail clearly instead of hanging on an unknown host key.
- Known hosts and normal password authentication are unchanged.

For a new host, connect once with the OpenSSH client (or add its host key) before
opening it in OpsTerm. Verification covers the new askpass regression test and
the full core/egui Rust suites.
