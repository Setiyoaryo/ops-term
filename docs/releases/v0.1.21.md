# OpsTerm v0.1.21

Delete saved devices from the device list.

- Right-click a device and choose **Delete device…**, or open **Edit** and use
  the new **Delete…** button.
- A confirmation dialog shows the device name and `host:port` before anything
  is removed.
- Deleting a saved device keeps currently open terminals running, but detaches
  them from the saved entry so reconnect prompts cannot use a deleted device.
- The sidebar and connect palette refresh immediately after deletion.

Verification: 175 egui tests and 74 core tests pass, along with Linux clippy
(`-D warnings`) and `cargo check` for the `x86_64-pc-windows-gnu` target.
