# OpsTerm v0.1.9

Refine the close-session, quit and restart confirmations within the existing egui interface.

- A padded dark card, subtle border/shadow and dim backdrop separate the dialog from terminal output.
- A small vector warning badge and stronger heading establish hierarchy; the session name or active-session count has its own inset panel.
- Shorter muted text explains the consequence. Generous right-aligned Cancel and solid muted-red action buttons have clear hover/pressed states.
- Wrapped session names fit the minimum supported window size.

Active-session confirmation policy, Cancel initial focus, Escape/backdrop dismissal, Ctrl+Enter explicit confirmation, first-frame protection and focus restoration are unchanged. No new assets or dependencies. This is a presentation change; the intermittent freeze investigation and automatic diagnostics from v0.1.8 remain separate and unresolved.
