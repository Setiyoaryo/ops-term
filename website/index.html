[ A FEW THINGS TO KNOW ]

Good questions.

Is OpsTerm free and open source?+

Yes. OpsTerm is available under the MIT license. You can use it, inspect the source, and contribute on GitHub.

Which platforms are supported?+

The published release is for Linux x86_64, built on Ubuntu 24.04. Other environments can build from source; check the repository for requirements and compatibility notes.

How do automatic updates work?+

The app checks GitHub Releases for new signed versions. Choose when to install and restart, so an update does not interrupt your active terminal sessions.

Can I make the text less bright?+

Yes. Open Settings → Appearance to choose a font, select Original, Soft, Warm or Cool, and adjust text brightness. Try the live palette preview above.
